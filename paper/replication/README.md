# Paper replication

This directory regenerates every figure and table in `paper/paper.tex`
from the published package code. The CI workflow runs it on every push
and asserts the resulting `paper_outputs.json` is byte-identical to the
committed snapshot — that's the backstop that keeps the paper's
numerical claims aligned with the code.

## Run

From the repository root:

```bash
pip install -e ".[viz,temporal,paper]"
python paper/replication/reproduce.py
```

For byte-identical reproduction with the exact dependency versions used
in the paper, see [`MANIFEST.toml`](MANIFEST.toml) — or, equivalently,
run against the locked tree via `uv sync --frozen`.

## What's reproducible

Two worked examples drive the paper. Both are deterministic:

1. **2012 US Presidential Convention speeches** (Kessler 2017's bundled
   corpus, 189 speeches, ~135K tokens) anchors the static analyses
   (keyness, collocations, semantic shift, networks). The corpus is
   public-domain US-government speech and is snapshotted to
   `data/conventions_2012.parquet` (294 KB, zstd-compressed) so the
   replication archive is fully self-contained — no network fetch at
   run time. The fallback path in `reproduce.py` re-downloads from
   `scattertext.SampleCorpora` only if the snapshot is missing.

2. **The bundled UK Hansard sample** (`pcd.load_hansard_sample()`,
   193 speeches across 2005–2023, four parties × four topics, frame
   shifts engineered at historically plausible inflection points)
   anchors the temporal stack (trajectory, changepoints, ITS,
   causal_impact, forecast, BOCPD). The sample is synthetic in prose
   but real-shaped in structure; the paper notes this honestly and
   points readers at the live `pcd.fetch_hansard()` adapter for real
   parliament.uk Hansard analysis.

All Monte Carlo paths in `causal_impact` use a fixed seed
(`seed=42`, `n_samples=1000`). All BOCPD and ETS / Holt fits are
deterministic given the input series. There is no randomness in any
output `reproduce.py` writes.

## CI

The `paper-replication` job in [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml)
re-runs `reproduce.py` and compares the regenerated `paper_outputs.json`
against the committed copy via schema assertions. Drift fails the build,
so paper claims cannot silently drift from the code.
